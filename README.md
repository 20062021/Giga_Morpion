# GIGA MORPION

---

> [!NOTE] À noter !
> Ce projet a été créé pour le fun, le but n'étant pas de créer le meilleur morpion 3D mais de s'entraîner à python sur un projet ensemble.



## Règles :

- pour le premier joueur qui joue, toutes les cases (à cocher) sont disponibles.
- ensuite le deuxième joueur ne peut cocher que certaines cases (celles d'un morpion sur les 9), et ainsi de suite.
- si une grille est fini, il n'y a plus rien à faire dessus.
- si (selon les règles) on doit jouer sur un morpion cloturé, alors on joue sur le morpion précédement joué (si celui-ci est fini également on revient au précédent, etc)

> [!WARNING]
> Ce projet n'est qu'en développement, et ne fonctionnera pas sur tous les commits de [main](https://github.com/20062021/Giga_Morpion)
